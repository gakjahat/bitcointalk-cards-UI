# Bitcointalk Modern UI

A userscript (Tampermonkey / Violentmonkey) that gives Bitcointalk.org a clean, responsive makeover without changing how the forum works.

## Features
- **Modern home & boards**: card layout, collapsible categories, live board/topic filter, Info Center summary
- **Mobile-friendly**: sticky top bar, swipeable navigation, tap-friendly pagination with jump-to-page
- **Neat thread view**: poster info rebuilt as a compact card (full, uncropped avatars, stat chips, rank, OP badge)
- **Signatures untouched**: isolated with Shadow DOM so banners and custom formatting look exactly as the author intended
- **Light / Dark / Auto** theme with 4 accent colors
- **Languages**: Auto, English, Indonesian
- Skins all other pages (profile, reply forms, etc.) to match

## Install
1. Install a userscript manager such as [Tampermonkey](https://www.tampermonkey.net/)
2. Open `bitcointalk-modern-ui.user.js` and click **Install**
3. Visit [bitcointalk.org](https://bitcointalk.org)

You can toggle the modern UI on/off from the userscript manager menu, or adjust everything via the gear icon in the top bar.

## Notes
This script only changes presentation in your browser. It does not collect data or send requests to any third party.
